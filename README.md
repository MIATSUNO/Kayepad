# Kayepad

A Kayepad é um espaço para escrever do seu jeito: criar, revisar, montar capas, ler e preparar suas obras para levar com você.

**[Abrir a Kayepad](https://kayepad.neocities.org/)** · **[Entrar no espaço de escrita](https://kayepad.neocities.org/site/main)** · **[Conhecer a Veristante](https://kayepad.neocities.org/site/veristante)**

## Para baixar

O aplicativo Android mais recente neste repositório é o **Kayepad for Writers 1.2.0**.
